# Фото в Word

Собирает документ Word из фото, скана или скриншота: выпрямляет лист, убирает синие печати и подписи, распознаёт текст и восстанавливает раскладку (колонки, таблицы, жирный, курсив, линейки для заполнения).

**Открыть:** https://kolins44.github.io/foto-v-word/

Работает прямо в браузере телефона или компьютера. Фото никуда не отправляется: распознавание идёт на самом устройстве. После первого открытия модуль сохраняется в браузере и дальше работает без интернета. На телефоне его можно добавить на главный экран (меню браузера → «Добавить на главный экран»).

Распознавание — Tesseract (tesseract.js 5.1.1, Apache-2.0), словари tessdata rus и eng (Apache-2.0).
